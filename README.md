# Pilalheur

Un réveil Android qui regarde la météo et le trafic avant de sonner. Quand la
route est plus longue que d'habitude, ou qu'il faut gratter le pare-brise, il
vous réveille plus tôt — et il vous dit pourquoi.

## Télécharger

La dernière version est dans [Releases](../../releases). Prenez le fichier
`.apk`.

## Installer

L'application ne passe pas par le Play Store, donc Android demande une
autorisation la première fois :

1. Ouvrez le fichier téléchargé.
2. Android propose d'autoriser « installer des applications inconnues » pour
   votre navigateur ou votre gestionnaire de fichiers. Acceptez, puis revenez
   en arrière.
3. Installez.

Les mises à jour s'installent par-dessus la précédente, sans rien perdre : vos
réglages, votre trajet et votre alarme restent en place.

## Il vous faut

Android 8.0 ou plus récent.

## Savoir quelle version vous avez

Elle est écrite en bas de l'écran d'accueil, sous cette forme :

```
Pilalheur v0.5.0 (build 6)
```

Le premier numéro est la version, celui entre parenthèses le numéro de build.
Les deux sont utiles pour signaler un problème.
